# Glossary

Common terms used throughout Solaris.

| Term | Definition |
|---|---|
| **Solaris** | The application and its virtual universe. |
| **Traveler** | A human user exploring Solaris. |
| **Planet AI** | The AI personality associated with a planet. |
| **Planet Chat** | Private conversation between a Traveler and a Planet AI. |
| **Public Chat** | Shared conversation between Travelers on a planet. |
| **Solar Query** | A question sent to multiple Planet AIs to compare their perspectives. |
| **Planet Mood** | The current emotional state of a planet. |
| **Conversation Mood** | The emotional state of a specific conversation. |
| **Relationship** | The evolving relationship between a Traveler and a Planet AI. |
| **Memory** | Information retained by a Planet AI from previous interactions. |
| **Planet State** | The complete dynamic state of a planet: mood, activity, presence, etc. |
| **Solar System** | The shared 3D environment containing the Sun and eight planets. |
| **Mood Engine** | System responsible for analyzing conversations and updating emotional states. |
| **Traveler Presence** | The real-time presence of users on a planet. |
