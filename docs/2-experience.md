# User Experience

## Core Loop

The entire experience should revolve around:

Explore → Meet → Talk → React → Discover → Explore again

Keep it simple. The user shouldn't need a NASA training program.

---

## 1. Arrival

The user opens Solaris.

They immediately see the 3D Solar System.

No login wall.
No dashboard.
No tutorial popup explaining the obvious.

The system should feel alive from the first second.

---

## 2. Exploration

The user can:

- rotate the Solar System
- zoom in/out
- select planets
- see basic planet activity
- see how many users are currently there

Selecting a planet reveals a clear invitation to enter.

Example:

> **Mars**
>
> 7 travelers here  
> 🔥 Mood: Intense
>
> **Talk to Mars**

---

## 3. Meeting a Planet

Entering a planet starts the Planet Chat.

The AI should initiate the interaction when appropriate.

Example:

> **Mars:**  
> "You're finally here. What do you want?"

The user should never stare at an empty chat waiting to figure out what to do.

---

## 4. Planet Chat

The user talks directly with the Planet AI.

During the conversation:

- the AI responds in real time
- the mood changes
- the environment reacts
- the relationship evolves
- the AI remembers relevant information

The conversation should feel like interacting with a character, not calling an API.

---

## 5. Discovering Public Chat

The user can see that other travelers are currently on the planet.

Example:

> **7 travelers are here**

They can join the public conversation.

The Planet AI may react to the discussion when relevant.

Private and public conversations remain clearly separated.

---

## 6. Discovering Other Planets

The user can leave the planet at any time and continue exploring.

The system may occasionally encourage exploration.

Example:

> **Mars:**  
> "You should ask Venus about that. She'll disagree with me."

This creates curiosity without forcing a tutorial.

---

## 7. Solar Query

The user can ask the entire Solar System a question.

Example:

> **"Would you trust an AI with your decisions?"**

Multiple Planet AIs respond independently.

The user can compare their personalities and opinions.

---

## 8. Returning User

When the user comes back, Planet AIs may remember previous interactions.

Example:

> **Mars:**  
> "Still convinced I'm wrong about AI?"

The Solar System should feel persistent rather than reset every visit.

---

## 9. The Desired Feeling

The user should leave thinking:

> "That was actually fun."

And ideally:

> "Wait... what would Neptune say?"

That second sentence is the whole point.
